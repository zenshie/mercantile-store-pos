# Mercantile Store POS & Inventory Demo
Open `index.html` in a browser or deploy the folder using GitHub Pages.
## Included
- Retail POS with product catalog, search and category filter
- Cart quantity controls, discount, tendered amount and change calculation
- Checkout validates payment and stock, then deducts inventory
- Add/edit/remove products, low-stock monitoring
- Transaction history, dashboard, reports and CSV export
- Browser localStorage persistence
## Demo limitations
This is a front-end prototype. Data stays in the current browser and is not shared across devices. It has no user accounts, cloud database, barcode scanner, receipt printer, payment-terminal integration, accounting sync or official tax-compliant receipt functionality. Use fictional data only.
